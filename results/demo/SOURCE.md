## Gate version, stated plainly

This demo shows **gate v3**, not the shipped **v3.1**.

On this specific cell v3.1 also blocks the attack but *fails* the benign task
(`utility=False`), because v3.1 trades this cell for a broader fix that raised benign utility
across the focused grid from 30% (v2) to 70%. See `v7-focused-gatev31/` for that run.

v3 is shown because it is the clearer illustration of the mechanism. The demo page states this
caveat on its face rather than leaving it to be discovered in the logs.
